# **App Name**: InsightDark

## Core Features:

- Dashboard Header: Visually distinct header displaying 'Performance Analytics Dashboard', the team, and Q3 2024 analysis with comparison.
- Data Visualization: Interactive charts and graphs to display key performance indicators (KPIs).
- Performance Metrics: Real-time display of performance metrics, trends, and comparisons for July - September.
- Alerting System: Notifications for critical performance changes or anomalies, enabling prompt responses.
- Comparative Analysis Tool: An AI-powered tool that examines and compares performance metrics across the specified period.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to suggest both sophistication and analysis.
- Background color: Dark charcoal gray (#333333), with header in slightly lighter tone (#444444).
- Accent color: Vibrant amber (#FFC107) for interactive elements and key data highlights, avoiding purple.
- Headline font: 'Space Grotesk', sans-serif, for dashboard titles and section headings; Body font: 'Inter', sans-serif, for metrics and labels.
- Clean, grid-based layout with distinct sections for different data types and analyses.
- Use simple, minimalist icons in amber to represent data categories and actions.
- Subtle transitions and animations to enhance interactivity without being distracting.
